Arquitectura AWS · Etapa 2

Pilares Estratégicos: Cómputo, Storage y Persistencia

Transformación desde el servidor monolítico de 3.7 GiB hacia tres capas desacopladas, elásticas y de alta disponibilidad

Pilar 1 · Cómputo

Amazon EC2 & Spot

Segregación completa de ambientes: Producción aislada (SOFI vs Clientes), Cloud Workstations para practicantes y pruebas de bajo costo con Spot Instances.

✓ Aislamiento de fallas · Discos EBS gp3
Pilar 2 · Almacenamiento

S3, EFS & Glacier

Estrategia de 3 niveles: S3 para contenidos LMS de practicantes, EFS para directorios de desarrollo compartidos y Glacier para archivo histórico de respaldos.

✓ Ciclo de vida automatizado · Elasticidad total
Pilar 3 · Persistencia

Amazon RDS PostgreSQL

Base de datos relacional administrada y aislada en subred privada. Copias de seguridad continuas automatizadas con restauración puntual en el tiempo (PITR) y cifrado KMS.

✓ Compatibilidad 100% Prisma ORM · Cero OOM
