Capas de Red en Amazon VPC
CIDR 10.0.0.0/16
Subred Pública · ALB + IGW (10.0.1.0/24)
Perímetro Seguro

El Application Load Balancer (ALB) es el único punto de entrada público. Gestiona la terminación HTTPS con certificados SSL/TLS emitidos por AWS Certificate Manager (ACM).

Defensa: Ningún servidor de aplicaciones ni base de datos queda expuesto a Internet.
Subred Privada de Cómputo (10.0.10.0/24)
Sin IP Pública

Instancia Amazon EC2 (t3.small) alojando sofi-backend (NestJS), SOFI-WEB y el bot de Discord. Solo recibe tráfico interno reenviado por el ALB mediante Security Groups.

Aislamiento: Cero puertos de cómputo abiertos; administración segura vía AWS SSM.
Subred Privada de Datos (10.0.100.0/24)
Blindaje RDBMS

Aloja Amazon RDS for PostgreSQL 16. Sin ruta hacia el Internet Gateway (acceso público bloqueado al 100%). Solo atiende consultas SQL originadas en la subred de cómputo.

Resiliencia: Snapshots automáticos diarios, retención inmutable y tolerancia a fallos.

Caché en el Borde

Resolución DNS autoritativa de dominios institucionales y distribución de contenido estático de SOFI-WEB mediante Edge Locations, amortiguando ataques de denegación de servicio (DDoS).

Eficiencia: Descarga del 70% del tráfico estático sin impactar la CPU del backend.
Amazon S3 · Material Formativo & LMS
Escalabilidad Ilimitada

Almacenamiento elástico de videos instructivos, manuales en PDF y copias de seguridad. Desbloquea la restricción de los 29 GB del disco raíz del VPS y elimina el riesgo de saturación.

Capacidad: 99.999999999% (11 nueves) de durabilidad sin mantenimiento de discos físicos.
AWS SSM · CloudWatch (Sin Puerto 22)
Cero Puertos SSH

Administración de servidores mediante túneles seguros HTTPS de AWS Systems Manager sin abrir SSH (puerto 22). Métricas en tiempo real y alertas de umbral con CloudWatch.

Operación: Trazabilidad total de comandos y respuesta inmediata ante picos de uso.
