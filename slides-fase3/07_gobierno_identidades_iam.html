Separación estricta: Personas usan MFA en consola; máquinas y tareas asumen credenciales rotativas.
👤 1. Identidades Humanas (Principio PoLP)
• Permisos asignados exclusivamente a Grupos, nunca a usuarios individuales.
• El grupo Developers-Practicantes tiene regla Deny estricta a Producción.
• Cuenta Root guardada bajo llave con MFA físico; cero llaves estáticas.
💻 2. Cómputo EC2 (Instance Profile)
• La máquina virtual no entiende roles por sí sola: el Instance Profile actúa de puente.
• Entrega credenciales temporales rotativas cada 6 horas vía metadatos (169.254.169.254).
• Erradica el peligro de ejecutar aws configure con llaves quemadas en disco.
📦 3. Contenedores Fargate (Dual Role)
• Task Execution Role: Lo usa AWS para descargar la imagen de ECR y enviar logs.
• Task Role: Lo asume tu código NestJS para subir archivos al bucket S3 del LMS.
• Desacoplamiento total: un atacante no puede robar imágenes de ECR desde la web.
