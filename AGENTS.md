# Reglas del Proyecto: Presentación Cloud AWS

## Diagramas, Arquitecturas y Flujos de Sistemas
- Para cualquier diseño, generación o revisión de diagramas, flujos o mapas de infraestructura, es mandatorio activar y aplicar la skill **`archify`** (`~/.gemini/antigravity-cli/skills/archify/SKILL.md`).
- Respetar el modelo C4, etiquetar todos los protocolos/puertos en cada arista (`HTTPS :443`, `TCP :5432`, `NFS :2049`, etc.) y agrupar por subredes y zonas de confianza.
